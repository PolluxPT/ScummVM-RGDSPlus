# ScummVM RG DS+ v1.0.0 — PT / EN

## Português

Aplicação independente ScummVM 2026.4.0 para Anbernic RG DS Plus, Stock OS V1.0 (20260915).

- GUI moderno e suporte de stylus/toque com calibração.
- Escolha entre só inferior e duplicação.
- Botão PT/EN no arranque com preferência guardada.
- Curva de volume suave e botões físicos.
- Ícone incluído em APPS/Imgs/ScummVM.png.
- Registo único dentro da aplicação.

**Para instalar:** descarrega `ScummVM_RGDSPlus_v1.0.0.zip`, extrai e copia o conteúdo de APPS para Roms/APPS no TF2. Numa atualização, une as pastas e preserva config/saves/games.

**Fontes completas:** `ScummVM_RGDSPlus_v1.0.0_Sources.zip` (fica no computador).
`SHA256SUMS.txt` contém as somas de verificação. Os ficheiros automáticos Source code do GitHub são o repositório de desenvolvimento, não o pacote de instalação.

Não inclui jogos. Outros modelos/firmwares precisam de validação. A versão do port é 1.0.0; a versão do ScummVM incluído é 2026.4.0.

## English

Standalone ScummVM 2026.4.0 for Anbernic RG DS Plus, Stock OS V1.0 (20260915).

- Modern GUI and calibrated stylus/touch support.
- Lower-screen-only and mirrored-display modes.
- Persistent PT/EN startup button.
- Gentle audio curve and physical volume buttons.
- Icon included at APPS/Imgs/ScummVM.png.
- One log inside the application directory.

**Install:** download `ScummVM_RGDSPlus_v1.0.0.zip`, extract it and copy the contents of APPS into Roms/APPS on TF2. When updating, merge directories and keep config/saves/games.

**Complete sources:** `ScummVM_RGDSPlus_v1.0.0_Sources.zip` (keep on your computer).
Checksums are in `SHA256SUMS.txt`. GitHub's automatic Source code files are the development repository, not the installation package.

Games are not included. Other models/firmwares require validation. The port version is 1.0.0; the included ScummVM version is 2026.4.0.
